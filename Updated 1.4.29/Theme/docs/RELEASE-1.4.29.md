# Theme 1.4.29 / Plugin 1.3.4 contract

- Production is an exact pair: Theme `1.4.29` and Alipasandi Service Content `1.3.4`.
- The Theme renders; the Plugin owns operational settings and mutations.
- Clinic name, structured address, display address and phone contain no built-in production fallback.
- The direct telephone route is emitted only from a valid E.164 option.
- Contact and appointment forms fail closed unless mail identity, phone route and relevant schedules pass the shared validators.
- Local Schema is either explicitly disabled or normalized by Rank Math from the canonical settings. Partial local entities are removed.
- Schema-marker repair is dry-run by default, Staging-only on apply, plan-hash bound, and forbidden from changing content hashes.
- Promotion requires the artifact-bound NAP freeze, signed explicit Front/Contact probes, the returned-HTML 1.4.29 contract and rendered NAP consistency evidence.

The parent delivery bundle contains the authoritative hashes and execution order.
