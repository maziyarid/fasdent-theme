DEPLOYMENT REQUIREMENTS
================================================================================

Before Production Deployment:

1. Deploy to staging environment with:
   - WP_ENVIRONMENT_TYPE=staging
   - Production-identical PHP 8.2+
   - Production-identical WordPress 6.4+

2. Run NAP Freeze:
   - NAP_Freeze::freeze_and_signoff(['approved' => true, 'owner_name' => '...'])
   - Verify all 17 fields are frozen

3. Run Runtime Evidence:
   - Execute health checks: run_health_checks()
   - Execute NAP consistency test: test_nap_consistency()
   - Execute booking/hours validation: validate_booking_hours()
   - Verify all checks pass

4. Verify Production Hard Gates:
   - See docs/production-checklist.md
   - All items must be checked before production deploy

5. Owner Approval:
   - NAP Freeze sign-off
   - Claims register approval
   - Horizon/Lead targets approval
