# چک‌لیست SEO پیش از انتشار نسخه جدید

این فایل بخشی از فرآیند انتشار است، نه جایگزین بررسی متخصص SEO یا ارزیابی پزشکی محتوا.

## ۱. تهیه نسخه پشتیبان قبل از تغییر

- از پایگاه داده و فایل‌های سایت نسخه پشتیبان کامل تهیه شود.
- فهرست URLهای فعلی از Sitemap، سرچ کنسول و Crawl سایت خروجی گرفته شود.
- برای هر URL این ستون‌ها ثبت شود: Status Code، SEO Title، Meta Description، Canonical، Robots، H1، تعداد لینک داخلی، صفحه جایگزین و Redirect موردنیاز.
- URLهای دارای Impression/Click/Backlink جداگانه علامت‌گذاری شوند.
- هیچ URL فعلی بدون تأیید فهرست Redirect تغییر نکند.

## ۲. کنترل معماری و محتوا

- هر صفحه فقط یک H1 داشته باشد و H2/H3 بر اساس سلسله‌مراتب واقعی محتوا باشند.
- چهار Landing Page خدمات مستقل باقی بمانند: ایمپلنت، روکش زیرکونیا، جراحی و لثه، درمان عمومی.
- محتوای مشابه یا کم‌ارزش به‌صورت صفحه تکراری منتشر نشود.
- مقالات از منوی اصلی حذف هستند، اما از فوتر و لینک‌های داخلی قابل دسترسی می‌مانند.
- برای محتوای پزشکی، نام نویسنده واقعی، تخصص، منابع، تاریخ انتشار و تاریخ بازبینی ثبت شود.

## ۳. کنترل فنی در Staging

- Title، Description، Canonical و Open Graph هر صفحه بررسی شود.
- فقط یک Canonical معتبر وجود داشته باشد و به URL قابل ایندکس اشاره کند.
- Breadcrumb ظاهری و BreadcrumbList Schema تست شود.
- Schemaهای Dentist/Service/Article با داده واقعی تست شوند؛ Review یا Rating ساختگی ممنوع است.
- تصاویر محتوایی ALT توصیفی و تصاویر تزئینی ALT خالی داشته باشند.
- Hero بدون Lazy Load و تصاویر پایین صفحه با Lazy Load باشند.
- width/height، WebP، srcset/sizes و عدم CLS تصاویر کنترل شود.
- هیچ صفحه مهمی noindex نباشد؛ Sitemap XML و robots.txt بررسی شوند.
- لینک‌های Navigation و خدمات `<a href>` واقعی باشند.
- FAQ در HTML صفحه موجود و بدون JavaScript نیز قابل خواندن باشد.
- نمایش 390، 768، 1199، 1200 و 1440 پیکسل بدون Horizontal Scroll بررسی شود.

## ۴. Redirect و انتشار

- هر URL تغییرکرده دقیقاً به نزدیک‌ترین جایگزین مرتبط با 301 هدایت شود؛ Redirect گروهی به صفحه اصلی ممنوع است.
- Redirect chain و loop وجود نداشته باشد.
- صفحات حذف‌شده بدون جایگزین، 404 واقعی و سبک برگردانند.
- پس از انتشار، Crawl مجدد، تست فرم‌ها، Sitemap و گزارش Coverage سرچ کنسول انجام شود.
- Core Web Vitals با تمرکز بر LCP، CLS و INP در موبایل بررسی و ثبت شود.

## ۵. معیار تأیید انتشار

- صفر URL مهمِ گم‌شده یا بدون تصمیم Redirect.
- صفر H1 تکراری در Templateهای اصلی.
- صفر Meta/Canonical/Schema تکراری ناشی از هم‌زمانی قالب و افزونه SEO.
- صفر لینک اصلی وابسته به JavaScript.
- صفر Horizontal Scroll در عرض‌های هدف.
- اطلاعات نام کلینیک، تلفن و آدرس در تمام صفحات یکسان باشد.
